## Scons

### Compiler le projet
Pour compiler le projet avec scons utiliser la commande suivante et remplace ``TARGET`` 
par le robot de votre choix:

Targets:
```
HERO
ICRA
SENTRY
SPIN_TO_WIN
STANDARD
```
Commande:
```
scons build target=TARGET
```

### Programmer le robot
Pour programmer le robot avec scons utiliser la commande suivante et remplace ``TARGET`` 
par le robot de votre choix:

Targets:
```
HERO
ICRA
SENTRY
SPIN_TO_WIN
STANDARD
```
Commande:
```
scons run target=TARGET
```
